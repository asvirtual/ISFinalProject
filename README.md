The report must be in pdf, max 10 pages, not counting figures, code and tables. Upload a single zipped file that contains everything you believe may be useful for the reader.

A typical report is structured as follows: 

Title and author names
Abstract: (say from 3-8 lines) describing the problem and what it has been done
Introduction: motivation about the problem and possibly pointers to the literature
Data description and exploration: describes where the data comes from and performs some quick exploratory analysis by means of graphs and summaries
Statistical methods: statistical methods applied and the results obtained
Conclusions
